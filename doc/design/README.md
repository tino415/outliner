# Design notes

Proposals for discussion, not decisions. Each note sets out the
context, how other tools do it, the options with their costs, a
recommendation and the questions that need an answer first.

Once a direction is agreed, the decision goes into [doc/adr](../adr/README.md)
as a new record, and the note stays here as background. Unlike the records,
notes can be edited.

- [Plugins and scripting](plugins-and-scripting.md): scripts kept in the
  outline that add commands, computed properties and capture templates.
- [Encrypted items](encrypted-items.md): items only trusted devices can
  read, kept out of the CLI and of agents.
